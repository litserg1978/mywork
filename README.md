# Шагая по планете | Investments Worldwide

Готовый статический лендинг без сборщика и внешних зависимостей.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере или загрузите все файлы на любой статический хостинг.
3. Перед публикацией замените `[email protected]` в `index.html` на реальный адрес.

## Файлы

- `index.html` — семантическая структура и весь контент.
- `styles.css` — дизайн, адаптивность и CSS-анимации.
- `script.js` — hover/click/focus-механика орбиты ресурсов.
- `robots.txt` и `sitemap.xml` — правила индексации и карта сайта.
- `og.png` — карточка сайта для Telegram, Facebook и других сервисов.
- `favicon.svg`, PNG-иконки и `site.webmanifest` — фирменные иконки сайта.
- `brand-seal.svg` и `brand-seal-512.png` — официальная эмблема проекта.
- `404.html` — страница для несуществующих адресов.
